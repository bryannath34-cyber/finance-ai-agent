ℹ️ Tentang Personal Finance AI Agent

Aplikasi manajemen keuangan mandiri berbasis cloud enterprise Oracle Cloud Infrastructure (OCI).

  • Arsitektur AI Hibrida: OCI GenAI Cohere Command A (Osaka) & Whisper Medium Speech.
  • Basis Data Mandiri: MySQL DB System Privat dengan buku besar nir-ubah (immutable ledger).
  • Keamanan: Argon2id password hash, proteksi CSRF, cookie HttpOnly, anti-IDOR.

👤 Edit Profil Pengguna

Perbarui informasi tampilan nama akun dan alamat email.

🔒 Ubah Kata Sandi

Gunakan minimal 8 karakter dengan kombinasi huruf dan angka.

🔄 Status Cadangan & Pemulihan

Sistem buku besar (ledger) keuangan diamankan menggunakan replikasi mandiri pada Oracle Cloud Infrastructure.

Status Backup Otomatis: ✓ Aktif (Harian 00:00 UTC)
Penyimpanan: OCI Private Object Storage
Point-in-Time Recovery: Hingga 7 Hari Terakhir

🛡️ Kebijakan Privasi & Keamanan

Data finansial Anda dikelola secara terisolasi di tenancy privat Anda:

  • Enkripsi End-to-End: Data diamankan dengan AES-256 saat tersimpan dan TLS 1.3 saat transit.
  • Tanpa Pelacakan Pihak Ketiga: Tidak ada analitik iklan atau pelacak eksternal yang diizinkan.
  • Isolasi AI OCI: Model GenAI Cohere dan Whisper berjalan di enclave komputasi OCI tanpa menyimpan data pelatihan.
